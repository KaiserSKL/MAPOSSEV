MAPOSSEV es una adecuacion del sistema MAPOS creado por Ramon Silva (https://github.com/RamonSilva20)

Se ha modificado la base de datos y el idioma para poder cumplir la necesidades del departamento de Soporte Técnico de la Secretaria de Educacion de Veracruz.

El proyecto se encuentra en estapas iniciales, haciendo sobre todo cooperacion con los ususarios para entregar un sistema que cumpla las necesidades de estos

Para la correcta intslacion y funcionamiento el servidor debera tener las siguientes caracteristicas

un servidor web (Apache u IIS)
MYSQL SERVER
PHP 8.3 o superior
Librerias composer https://getcomposer.org/
